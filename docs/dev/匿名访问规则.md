实现统一匿名访问规则。

### 规则

匿名接口固定使用以下 URL 结构：

```text
Gateway 外部路径：/api/*/public/*
Service 内部路径：/*/public/*
```

只允许 `public` 出现在固定层级，并且 `public` 后只匹配一层，禁止使用 `**` 放宽匹配。

### 修改

1. **gateway-service**

   * Spring Security 增加 `/api/*/public/*` → `permitAll()`。
   * 其他请求保持现有认证逻辑。
   * 匿名请求不得要求 JWT / Redis Session 校验。

2. **platform-base**

   * `SecurityFilterChain` 增加 `/*/public/*` → `permitAll()`。
   * `InternalAuthenticationFilter` 对 `/*/public/*` 使用相同规则跳过内部认证 Header、签名和 Redis Authority 校验。
   * 其他请求保持现有逻辑不变。

3. **测试**

   * `/api/system/public/test`、`/system/public/test` 应匿名通过。
   * `/api/system/user/public/test` 不得被识别为匿名。
   * `/api/system/public/test/other` 不得被识别为匿名。
   * 原有登录、JWT、内部签名和 `@PreAuthorize` 权限链不得受影响。

不要增加 `@PublicApi` 注解，不增加新的匿名白名单配置机制。
