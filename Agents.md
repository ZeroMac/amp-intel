# Maven项目规则.
| POM                             | 回答的问题                     |
| ------------------------------- | ------------------------- |
| `/pom.xml`                      | **这个代码仓库有哪些模块？**          |
| `/platform-bom/pom.xml`         | **这些库用什么版本？**             |
| `/platform-parent/pom.xml`      | **Java 项目按什么规则编译、测试、打包？** |
| `/services/pom.xml`             | **目前有哪些微服务？**             |
| `/services/xxx-service/pom.xml` | **这个服务具体需要哪些能力？**         |
